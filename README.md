# PlanHarbor — Coming soon

A small static holding page for planharborapp.com.

The site consists of index.html with inline CSS, the custom-domain CNAME file,
and this README. It uses no JavaScript, forms, tracking, external fonts or images.
The page follows the visitor's light or dark display preference.

GitHub Pages publishes from the main branch, repository root.
Custom domain: planharborapp.com.

Once DNS points to GitHub Pages and GitHub has issued the certificate, enable
Enforce HTTPS in this repository's Settings → Pages.
